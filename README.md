# Kaggle Playground

My work on Kaggle's Playground Series: small tabular prediction competitions, used to practise building and validating ML models. One folder per episode.

| Episode | Task | Metric | Status |
|---|---|---|---|
| [S6E10: Predicting Airline Satisfaction](s6e10-airline-satisfaction/) | Binary classification | ROC AUC | In progress (deadline 31 Oct 2026) |

## Layout

Each episode folder follows the same structure, loosely based on [Cookiecutter Data Science](https://cookiecutter-data-science.drivendata.org/). Data, models and predictions are git-ignored.
